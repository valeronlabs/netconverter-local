# NetConverter Local

NetConverter Local is the Docker appliance for collecting, reviewing and comparing firewall, router and switch configurations on your own network. It is part of [NetConverter](https://netconverter.ai), by ValeronLabs LLC.

## Installation

NetConverter Local is distributed as prebuilt Docker images. The installation files for the current release, 2.0.7.4, are being republished here in that form.

Until they are posted, please contact your NetConverter representative for the current package.
